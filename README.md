# ☕ Java Development & Core OOP Concepts

Welcome to my Java repository! This repository serves as a collection of practical code examples, exercises, and reference implementations covering the core concepts of Object-Oriented Programming (OOP) and fundamental Java features.

---

## 📂 Topic Overview & Code Examples

This repository covers the following core areas of Java development:

### 🔹 Object-Oriented Programming (OOP)
* **Classes & Objects (`Class`, `Petholder`):** Creating classes, instantiating objects, and managing constructors.
* **Inheritance (`Inheritance`):** Code reusability using superclasses and subclasses.
* **Encapsulation (`Encapsulation`):** Protecting data structures using `private` fields along with `getter` and `setter` methods.
* **Abstraction (`Abstract.java`):** Utilizing abstract classes to define structured interfaces.
* **Polymorphism & Overloading (`Overloading`):** Method overloading for flexible parameter handling.

### 🔹 Data Structures & Language Concepts
* **Data Types & Arrays (`Datatypes`, `Arrays`):** Primitive data types, reference types, and multi-dimensional arrays.
* **Enums & Immutability (`Enums`, `Immutable`):** Working with predefined constant sets and creating immutable objects.
* **Control Structures (`Loop`):** Efficient execution flow using loops (`for`, `while`, `enhanced for`).
* **Package Structure (`package myPackage`):** Clean modularization and encapsulation of source code.
